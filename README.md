# Pokédex - API & CRUD con React

Este proyecto es una aplicación web construida con React y Vite que permite buscar Pokémon utilizando la [PokéAPI](https://pokeapi.co/) pública y gestionar un equipo de Pokémon favoritos mediante un servidor local (JSON Server) aplicando las operaciones CRUD completas (Crear, Leer, Actualizar y Eliminar).

## Tecnologías utilizadas

* **Frontend:** React + Vite
* **Backend Simulado:** JSON Server
* **Estilos:** CSS / (Si usaste algún framework como Bootstrap o Tailwind, ponlo aquí)
* **Peticiones HTTP:** Fetch API (Async/Await)

## Funcionalidades (CRUD)

* **Read (GET):** Consulta y muestra la lista de Pokémon en tu equipo desde la base de datos local, además de buscar Pokémon en la PokéAPI.
* **Create (POST):** Agrega un nuevo Pokémon capturado a tu equipo.
* **Update (PATCH):** Actualiza atributos específicos de un Pokémon en tu equipo (ej. subir de nivel o marcar como favorito).
* **Delete (DELETE):** Elimina (libera) un Pokémon de tu equipo.
